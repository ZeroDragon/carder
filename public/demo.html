📖 Documentación Completa de Apple Wallet Passes

🎯 Tipos de Passes Disponibles

  • generic - Pass genérico para cualquier uso personalizado
  • eventTicket - Boletos de eventos (conciertos, deportes, teatro, etc.)
  • boardingPass - Pases de abordar (requiere transitType)
  • coupon - Cupones y descuentos
  • storeCard - Tarjetas de lealtad de tiendas

📊 Campos del Pass (Fields)

Los campos se dividen en varias categorías según su posición visual:

1. Primary Fields Requerido

El campo más grande y prominente en el frente del pass.

  • key - Identificador único del campo (required)
  • label - Etiqueta descriptiva (ej: "Nombre")
  • value - Valor del campo (ej: "Juan Pérez")
  • attributedValue - Valor formateado (ej: valor numérico con formato de moneda)
  • changeMessage - Mensaje cuando cambia el valor (ej: "Puntos actualizados a %@")
  • textAlignment - Alineación del texto (left, center, right, natural)
  • dateStyle - Formato de fecha (none, short, medium, long, full)
  • timeStyle - Formato de hora (none, short, medium, long)
  • isRelative - Si la fecha es relativa (ej: "hace 2 horas")
  • ignoresTimeZone - Ignorar zona horaria
  • currencyCode - Código de moneda (ej: "USD", "MXN")
  • numberStyle - Estilo de número (decimal, percent, scientific, spellOut)
  • dataDetectorTypes - Tipos de datos detectables (phone, link, address, calendar)

2. Secondary Fields Opcional

Campos secundarios que aparecen debajo del primary field.

  • Mismas propiedades que Primary Fields

3. Auxiliary Fields Opcional

Campos auxiliares con información adicional.

  • Mismas propiedades que Primary Fields
  • row - Número de fila (0 o 1) para event tickets

4. Header Fields Opcional

Campos que aparecen en el encabezado superior del pass.

  • Mismas propiedades que Primary Fields

5. Back Fields Opcional

Campos visibles al girar el pass (parte trasera).

  • Mismas propiedades que Primary Fields

6. Additional Info Fields iOS 18+

Información adicional para Event Tickets con el nuevo diseño.

  • Mismas propiedades que Primary Fields
  • Disponible solo para eventTicket

🎨 Configuración de Colores

  • backgroundColor - Color de fondo del pass (ej: "#1a1a2e")
  • foregroundColor - Color del texto (ej: "#ffffff")
  • labelColor - Color de las etiquetas (ej: "#e94560")
  • stripColor - Color de la franja (opcional, ej: "#667eea")
  • footerBackgroundColor - Color del footer (iOS 18+)

🖼️ Imágenes

Solo necesitas proporcionar las versiones @2x (alta resolución). El sistema generará automáticamente las versiones 1x redimensionando. Las imágenes pueden estar en formato PNG o JPG/JPEG:

  • icon@2x.png Requerido - Icono del pass (máximo 58x58, se genera versión 1x de 29x29)
  • logo@2x.png Opcional - Logo en el centro superior (máximo 240x240, se genera versión 1x de 120x120)
  • background@2x.png iOS 18+ Opcional - Imagen de fondo completa (se genera versión 1x escalada)
  • thumbnail@2x.png Opcional - Miniatura para boarding passes y event tickets (máximo 600x600, se genera versión 1x de 300x300)
  • strip@2x.png Opcional - Imagen de fondo en la parte superior (máximo 780x246, se genera versión 1x de 390x123)

Nota: El sistema redimensionará y convertirá automáticamente las imágenes JPG a PNG si es necesario, manteniendo la proporción. Las versiones 1x se generan automáticamente a partir de las versiones @2x.

📱 Códigos de Barras

Formatos Disponibles:

  • PKBarcodeFormatQR - Código QR (más común)
  • PKBarcodeFormatPDF417 - PDF417 (para documentos)
  • PKBarcodeFormatAztec - Código Aztec (compacto)
  • PKBarcodeFormatCode128 - Code 128 (barra estándar)

Propiedades:

  • format - Formato del código de barras (required)
  • message - Contenido del código (required)
  • messageEncoding - Codificación (default: "iso-8859-1")
  • altText - Texto alternativo visible debajo del código

⚙️ Propiedades Adicionales

  • serialNumber - Número de serie único del pass
  • description - Descripción del pass (required)
  • organizationName - Nombre de la organización (required)
  • logoText - Texto del logo (opcional)
  • expirationDate - Fecha de expiración del pass
  • relevantDate - Fecha relevante para mostrar el pass
  • relevantDates - Array de intervalos relevantes (iOS 18+)
  • groupingIdentifier - Identificador para agrupar passes
  • voided - Si el pass está invalidado
  • sharingProhibited - Si se prohibe compartir el pass
  • suppressStripShine - Suprimir efecto de brillo en la franja
  • userInfo - Información personalizada arbitraria
  • webServiceURL - URL del web service para actualizaciones
  • authenticationToken - Token de autenticación para web service
  • associatedStoreIdentifiers - IDs de apps asociadas

📍 Ubicaciones (iOS 18+ Live Activities)

Para activar Live Activities en event tickets:

  • latitude - Latitud de la ubicación
  • longitude - Longitud de la ubicación
  • relevantText - Texto descriptivo de la ubicación

📡 Beacons (iOS 18+ Live Activities)

Para activar Live Activities con beacons:

  • proximityUUID - UUID del beacon
  • major - Número mayor (opcional)
  • minor - Número menor (opcional)
  • relevantText - Texto descriptivo

📲 NFC

Para passes compatibles con NFC:

  • message - Contenido del mensaje NFC
  • encryptionPublicKey - Clave pública para encriptación

✈️ Transit Type (para Boarding Pass)

  • PKTransitTypeAir - Transporte aéreo
  • PKTransitTypeBoat - Transporte marítimo
  • PKTransitTypeBus - Transporte terrestre (autobús)
  • PKTransitTypeTrain - Transporte ferroviario
  • PKTransitTypeGeneric - Transporte genérico

🆕 Novedades de iOS 18+

  • Poster Event Tickets - Nuevo diseño para boletos de eventos
  • Semantic Boarding Passes - Pases de abordar mejorados (iOS 26+)
  • Live Activities - Actividades en vivo activadas por locations, beacons o relevantDates
  • Event Guide - Guía del evento con botones adicionales
  • useAutomaticColors - Cálculo automático de colores basado en imagen de fondo
  • upcomingPassInformation - Información sobre passes futuros relacionados (iOS 26+)

🔌 API Endpoints

POST /pass

Genera y descarga un archivo .pkpass

Content-Type: application/vnd.apple.pkpass

Body: JSON con datos del pass

POST /pass/json

Genera un pass y lo devuelve como JSON

Content-Type: application/json

Body: JSON con datos del pass

GET /health

Verifica el estado del servidor

Response: { status: "ok", timestamp: "..." }

💻 Ejemplo de Código

// Ejemplo básico con fetch
const response = await fetch('http://localhost:3000/pass', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    type: 'generic',
    description: 'Mi Pass Personalizado',
    organizationName: 'Mi Empresa',
    logoText: 'LOGO',
    backgroundColor: '#1a1a2e',
    foregroundColor: '#ffffff',
    labelColor: '#e94560',
    primaryFields: [{
      key: 'name',
      label: 'Nombre',
      value: 'Juan Pérez'
    }],
    barcode: {
      format: 'PKBarcodeFormatQR',
      message: 'https://miempresa.com/pass/12345',
      altText: '12345'
    }
  })
});

const blob = await response.blob();
const url = window.URL.createObjectURL(blob);
const a = document.createElement('a');
a.href = url;
a.download = 'mi-pass.pkpass';
a.click();

// Ejemplo con imágenes (en base64)
const image2xBase64 = 'data:image/jpeg;base64,iVBORw0KGgoAAAANS...'; // Tu imagen @2x en base64 (puede ser JPG)

const response = await fetch('http://localhost:3000/pass', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    type: 'eventTicket',
    description: 'Boleto de Concierto',
    organizationName: 'Concierto Inc.',
    backgroundColor: '#1a1a2e',
    foregroundColor: '#ffffff',
    images: {
      icon2x: image2xBase64,
      background2x: image2xBase64,
      thumbnail2x: image2xBase64
    },
    primaryFields: [{
      key: 'event',
      label: 'Evento',
      value: 'Concierto de Rock'
    }],
    barcode: {
      format: 'PKBarcodeFormatQR',
      message: 'https://miempresa.com/ticket/12345',
      altText: '12345'
    }
  })
});
Nota sobre imágenes: Solo necesitas proporcionar las imágenes @2x (alta resolución). El backend generará automáticamente las versiones 1x redimensionando. Las imágenes pueden estar en formato PNG o JPG/JPEG, el sistema convertirá automáticamente si es necesario.

🔄 Actualización de Passes

Configuración para Web Service

Para habilitar actualizaciones automáticas de passes:

  • webServiceURL - URL base de tu web service
  • authenticationToken - Token para autenticar requests

El web service debe implementar los endpoints:

  • GET /v1/passes/{passTypeIdentifier}/{serialNumber}
  • POST /v1/devices/{deviceLibraryIdentifier}/registrations/{passTypeIdentifier}/{serialNumber}
  • DELETE /v1/devices/{deviceLibraryIdentifier}/registrations/{passTypeIdentifier}/{serialNumber}
  • GET /v1/devices/{deviceLibraryIdentifier}/registrations/{passTypeIdentifier}
  • POST /v1/log
